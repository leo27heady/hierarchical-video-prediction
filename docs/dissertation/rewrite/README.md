# Dissertation rewrite policy

The files in this directory are the authoritative **English** dissertation sources.

- Write, revise and review all prose, tables, captions, references and figure annotations in
  English.
- Do not start or maintain a parallel Ukrainian rewrite during the active scientific programme.
- Existing Ukrainian headings, archival originals and `[UA-PASS: ...]` markers are provenance or
  unresolved genre notes; they do not authorize translation work.
- If a Ukrainian submission is later required, localize only after the English scientific text is
  frozen and only after an explicit author request.
- Apply scientific changes directly to these sources, not only to planning documents.
