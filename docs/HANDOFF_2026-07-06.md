## 8. METHODOLOGY LESSONS (all measured on this campaign; cite in CH4 §4.5.5 / threats)

1. **Effective-loop formula.** Size memory span against
   L_eff = world/(speed·(1−p_hold)), NOT world/speed — hold frames consume slots without
   advancing the pan. The 48-slot arm's 192-frame span fell short of its own target (~196–213)
   and diluted the effect; the 56-slot span-224 fix is what passed. (hgrid3: 768/(4·0.9)≈213.)
2. **The AE-reuse trap.** Reusing a frozen AE across testbed variants forced ×4 wavenumber
   scaling → world became exactly viewport-periodic (crop MSE 0.000000) → retrieval landmarks
   destroyed → memory slots became measured attention COST (40k LOSS). Rule: fresh AE per
   testbed variant; share one AE only within a campaign.
3. **Checkpoint-collision prefixes.** Two live collisions (legacy loopmom names `856c51a`, then
   cross-dataset names `f65f9f9`) → arm names are now dataset-derived-prefixed
   (`hgpc-`/`hgrid2pc-`/`hgrid3pc-`). Never name gate arms without the dataset prefix.
4. **Evaluation power (--eval_nb).** nb=24 was adequate for loopmom-magnitude effects (+0.0135)
   but underpowered for ~+0.002; the pre-registered 4× widening (nb=96) flipped nulls to
   CI-clean wins on the SAME checkpoints. A null read requires a power argument against the
   plausible effect size; disclose both reads.
5. **iid vs clustered CIs.** Rollout records have lag-1 autocorr +0.86 — frame-iid bootstrap is
   2–7× too narrow; ALWAYS clip-level cluster bootstrap (`rhvd.paired_ci`), empty-fg (21.5%)
   excluded to a bg-only row. mem_gate single-step CIs are sample-iid — quote only cells that
   survive a 2–3× design-effect widening (disclosed in CH4 §4.5.4).
6. **npz `sharp` field = chunk-batch mean duplicated per record** — valid for overall means and
   trend curves only; never per-bin/per-clip.
7. **Pre-commit decision rules before evidence.** The disambiguation R1/R2/R3 rule and the pair
   gate were written before their runs and honored exactly (incl. declining the Tier-A grid on
   RED). This is the campaign's strongest validity asset — keep the pattern.
8. **Seed variance honesty.** Effects replicate but magnitudes vary 2.7× (hgrid3) and onsets
   vary (Claim-1 h25 vs h1); claim the replicated feature (win + mid-horizon peak; span
   threshold), not seed-specific detail.
9. **Emergence needs budget.** Retrieval is a late capability (null@6k → win@20k, both seeds;
   hgrid variants needed 40k). Short-budget ablations spuriously kill memory mechanisms.
10. **Operational:** one training job at a time unless combined VRAM provably <15 GB (evals may
    overlap); 3392-token arms = 7.38 GB each, never two; WDDM spill guards abort >10 s steps;
    EBT imports need `hvp_rev/ebt_stubs/`; mem_gate 6k-vs-20k comparisons share the CRN eval
    set by design.
