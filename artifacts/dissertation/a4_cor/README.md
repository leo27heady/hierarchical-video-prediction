# Джерельні дані рисунка калібрування A4-COR

Цей каталог містить незмінені копії запечатаних артефактів із робочої гілки
`hierarchical-video-prediction-path-b`, використані для нижньої частини рисунка 4.3 дисертації.
Копії додано до репозитарію, щоб рисунок можна було відтворити без доступу до локального каталогу
великих контрольних точок.

| Файл | SHA-256 | Призначення |
|---|---|---|
| `article4_schedule_calibration_2026-09-01.json` | `8556e9b07b0e01bb65511f23c075fc96cd5f325483d70f245669b444cf65429b` | парне правило вибору зрізу й хеші первинних журналів |
| `flat_recent_seed0_validation_metrics.jsonl` | `d4f897831a74e85387b7aee3101463e9acb57a355766f526a2fb61414d75ba37` | 15 точок плоскої конфігурації через кожні 2 000 кроків |
| `balanced_recent_seed0_validation_metrics.jsonl` | `116de2a709650ea33da0adf4e5750ba665efe0531a0b5093a1092f0c92911a43` | 15 точок збалансованої ієрархічної конфігурації |

Дві траєкторії мають ініціалізацію 0 і бюджет 1 792 токени. Вони обґрунтовують лише вибір
30 000 кроків для повної матриці; їх не можна використовувати як доказ переваги певного пакета.
Первинні записи в JSON аналізу містять абсолютні локальні шляхи для аудиту походження, але
генератор рисунка читає лише копії з цього каталогу.

Відтворення з кореня репозитарію:

```powershell
python scripts/generate_ch4_schedule_calibration.py
python scripts/audit_ukrainian_dissertation.py
```
